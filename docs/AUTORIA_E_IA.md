# Autoria, participação e uso de IA

O edital entregue com o projeto exige que os integrantes compreendam a linguagem,
os conceitos e as decisões da implementação. A verificação oral insuficiente de
autoria ou de apropriação pode resultar em nota zero para o grupo. IA é permitida
como apoio, com declaração das ferramentas, finalidades e verificações realizadas.

Este arquivo não comprova a autoria da equipe. O guia ajuda a estudar, mas cada
integrante precisa conseguir modificar, prever e explicar o comportamento real.

## Registro desta revisão

Em 02/11/2026, o Codex foi usado, a pedido do usuário, para ler o projeto e os
documentos fornecidos, revisar o código, corrigir tratamento de erros, adicionar
comentários e testes, reescrever o README e preparar o guia de estudos.
As verificações efetivamente executadas pelo agente estão no relatório.
Elas não equivalem a verificações realizadas pessoalmente pelos estudantes.

Os arquivos originais mencionavam uso de Claude em várias etapas do desenvolvimento
e testes de mutação anteriores. O ZIP, sozinho, não permite confirmar esse histórico.
A equipe deve registrar o que realmente ocorreu, sem adotar aquelas afirmações
automaticamente. A integração opcional com Claude no produto é verificável no código;
isso é diferente de identificar quem ou qual ferramenta escreveu cada módulo.

Uma divisão futura de estudo não é histórico de implementação. Nos ensaios, alternem
os papéis: explicar o fluxo, operar a demonstração e fazer perguntas. Todos devem
passar pelos três papéis e estudar também os módulos fora de sua participação original.

## Evidências úteis de compreensão

1. Explicar um comando novo desde os tokens até o índice do pixel no C.
2. Prever a imagem antes de executar e justificar cada diferença encontrada.
3. Provocar um erro de cada fase e localizar a regra que o detecta.
4. Alterar uma coordenada solicitada na hora e conferir o resultado.
5. Explicar quais partes foram apoiadas por IA e como foram verificadas.

Não memorizem uma declaração coletiva de compreensão sem realizar essas atividades.
